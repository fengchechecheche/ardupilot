这个 Lua 脚本是用于 **ArduPilot**（无人机飞控系统）环境的 UART 数据记录脚本。让我详细分析其功能：

## 主要功能
该脚本从 **UART 串口** 读取数据，解析为特定格式，然后将数据记录到 **数据闪存（DataFlash）** 中。

## 脚本结构分析

### 1. **初始化阶段**
```lua
-- 查找脚本串口（通常是 UART）
local port = serial:find_serial(0)
-- 设置波特率 9600，禁用流控制
port:begin(9600)
port:set_flow_control(0)
```

### 2. **数据格式**
脚本期望接收的数据格式为：
- **3个逗号分隔的数值**（如：`123.45,67.89,987.65`）
- 以 `\r` 或 `\n` 结尾
- 每个字段最大长度 20 个字符
- 必须是数字格式（通过 `tonumber()` 转换）

### 3. **解码逻辑** (`decode` 函数)
- 按字节读取串口数据
- 使用逗号作为分隔符
- 遇到回车/换行时完成一帧数据的解析
- 验证数据完整性和格式

### 4. **数据记录** (`update` 函数)
```lua
logger.write('SCR','Sensor1, Sensor2, Sensor3','fff',table.unpack(log_data))
```
- 将解析的3个数值记录到 DataFlash
- 使用 'SCR' 作为日志类型标识符（必须≤4个字符）
- 使用 'fff' 格式表示3个浮点数
- **自动添加时间戳**（微秒精度）

### 5. **主循环**
- 每 100 毫秒执行一次 `update` 函数
- 检查串口是否有可用数据
- 处理所有待读字节

## 应用场景
这个脚本典型用于：
1. **外部传感器数据记录**（如 GPS、IMU、气压计等）
2. **地面站数据采集**
3. **调试信息记录**
4. **第三方设备数据集成**

## 关键特性
- **错误处理**：无效数据会被丢弃
- **数据验证**：确保接收到完整的三字段数据
- **时间戳**：自动添加高精度时间戳
- **轻量级**：适合资源受限的嵌入式环境

## 使用注意事项
1. **波特率**：硬编码为 9600，可能需要根据实际设备调整
2. **数据格式**：发送设备必须按照 `值1,值2,值3\r\n` 的格式发送
3. **日志类型**：'SCR' 不能与其他日志类型冲突
4. **字段数量**：硬编码为3个字段，如果需要更多需要修改脚本

这个脚本是 ArduPilot 中典型的外设数据集成方案，可以将第三方传感器的数据无缝整合到飞控系统的数据记录中。
