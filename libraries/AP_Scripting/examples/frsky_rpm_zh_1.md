# FrSky RPM遥测发送脚本分析

这是一个用于通过FrSky遥测链路发送RPM（转速）信息的Lua脚本，支持SPort和FPort协议。

## 主要功能

### 1. **RPM数据遥测传输**
- 通过FrSky遥测链路将两个RPM传感器数据发送到遥控器
- 支持多种FrSky协议：
  - SPort协议（SERIAL_PROTOCOL=4,10）
  - FPort协议（SERIAL_PROTOCOL=23）

### 2. **OpenTX兼容性**
- 使用OpenTX原生的RPM数据ID：0x0500-0x050F
- 选择未使用的ID 0x050E和0x050F避免冲突
- 传感器ID使用0xE4（索引4）

### 3. **双RPM传感器支持**
- 轮流发送两个RPM实例的数据（索引0和1）
- 每个实例有独立的数据ID

## 工作流程

### 初始化配置
1. **循环时间**：每250毫秒运行一次
2. **数据帧类型**：使用0x10（数据响应帧）
3. **传感器ID**：0xE4（SPort传感器索引4）
4. **数据ID分配**：
   - 实例0：0x050E
   - 实例1：0x050F

### 主循环（250ms间隔）
1. **获取RPM数据**：通过`RPM:get_rpm(instance)`获取指定实例的RPM值
2. **发送遥测数据**：
   - 使用`frsky_sport:sport_telemetry_push()`发送数据
   - 参数：传感器ID、数据帧类型、数据ID、RPM值
3. **切换实例**：每次循环交替发送两个实例的数据
4. **回调通知**：成功发送后调用回调函数显示调试信息

## 技术实现

### 1. **FrSky协议适配**
```lua
-- SPort协议使用ID 0,2,3,6（协议4）和7,13,20,27（协议10）
-- FPort协议不使用特定ID
-- 因此选择未冲突的传感器ID 0xE4
```

### 2. **RPM数据ID映射**
- OpenTX标准RPM数据ID范围：0x0500-0x050F
- 脚本使用最后两个ID：0x050E和0x050F
- 如果确定是唯一的RPM传感器，可以使用0x0500和0x0501

### 3. **数据发送机制**
```lua
-- 发送RPM数据到FrSky遥测
frsky_sport:sport_telemetry_push(sensor_id, sport_data_frame, data_ids[instance], rpm)
```

### 4. **循环调度**
```lua
-- 轮流发送两个RPM实例
rpm_idx = (rpm_idx+1)%2  -- 在0和1之间切换
```

## 配置要求

### 1. **飞控串口配置**
- 选择一个串口用于FrSky遥测
- 设置对应参数：
  - SERIALx_PROTOCOL = 4, 10 或 23
  - SERIALx_OPTIONS = 0（默认）

### 2. **RPM传感器配置**
- 确保RPM传感器正确连接和配置
- 在ArduPilot中设置RPM参数

### 3. **脚本参数说明**
```lua
local loop_time = 250        -- 循环间隔（毫秒）
local sport_data_frame = 0x10 -- 数据帧类型
local sensor_id = 0xE4        -- 传感器ID（SPort索引4）
```

## 调试与监控

### 1. **地面站消息**
- 发送成功时：`"rpm_data_sent() 0: 1250"`（实例编号和RPM值）
- 尝试发送时：`"send_rpm_data() 0, 1250"`

### 2. **遥测接收**
- 在OpenTX遥控器上配置相应的RPM传感器显示
- 使用0x050E和0x050F作为数据ID

## 应用场景

1. **多旋翼/直升机监控**：监控电机或主旋翼转速
2. **固定翼发动机监控**：监控螺旋桨发动机转速
3. **赛车无人机**：实时监控电机性能
4. **调试工具**：通过遥测实时查看RPM传感器读数

## 兼容性说明

### 支持的协议
1. **SPort（串行协议4）**：
   - 传统SPort协议
   - 使用ID 0,2,3,6
   
2. **SPort（串行协议10）**：
   - 智能端口协议
   - 使用ID 7,13,20,27
   
3. **FPort（串行协议23）**：
   - 双向通信协议
   - 不占用特定ID，更灵活

### 传感器ID选择原则
- 避开已被协议占用的ID
- 选择索引4（0xE4）通常安全
- 可根据实际配置调整

## 安全特性

1. **数据验证**：检查RPM值是否为nil再发送
2. **错误处理**：发送失败时通过回调函数通知
3. **循环保护**：确保两个实例轮流发送，避免重复
4. **调试信息**：提供详细的地面站消息便于故障排查

## 扩展性

### 增加更多RPM实例
```lua
-- 修改为支持更多实例
local data_ids = {
  [0] = 0x050E,
  [1] = 0x050F,
  [2] = 0x050D,
  [3] = 0x050C,
}

-- 修改循环逻辑
rpm_idx = (rpm_idx+1)%4  -- 支持4个实例
```

### 调整发送频率
```lua
-- 根据需求调整循环时间
local loop_time = 100  -- 增加到10Hz
```
