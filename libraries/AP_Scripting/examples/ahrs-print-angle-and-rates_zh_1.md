# 姿态角与角速度打印脚本分析

这个Lua脚本用于以1Hz频率实时显示飞行器的姿态角和角速度信息。

## 主要功能

### 1. **姿态角监测**
- 实时获取飞行器的三个姿态角：
  - **横滚角（Roll）**：飞行器绕X轴旋转的角度
  - **俯仰角（Pitch）**：飞行器绕Y轴旋转的角度
  - **偏航角（Yaw）**：飞行器绕Z轴旋转的角度
- 将所有角度从弧度转换为度数（°）

### 2. **角速度监测**
- 实时获取飞行器的三个轴向角速度：
  - **横滚角速度（Roll Rate）**：绕X轴旋转的角速度
  - **俯仰角速度（Pitch Rate）**：绕Y轴旋转的角速度
  - **偏航角速度（Yaw Rate）**：绕Z轴旋转的角速度
- 将所有角速度从弧度/秒转换为度/秒（°/s）
- 包含错误处理：如果获取失败，角速度值设为0

### 3. **数据输出**
- 通过地面站消息以格式化字符串输出所有数据
- 输出格式示例：`"Ang R:15.2 P:-3.5 Y:45.0 Rate R:12.3 P:0.5 Y:-2.1"`

## 工作流程

### 主循环（1Hz运行）
1. **获取姿态数据**：
   - 通过`ahrs:get_roll()`、`ahrs:get_pitch()`、`ahrs:get_yaw()`获取姿态角
   - 使用`math.deg()`将弧度转换为角度

2. **获取角速度数据**：
   - 通过`ahrs:get_gyro()`获取陀螺仪数据（返回向量）
   - 提取X、Y、Z分量并转换为度/秒
   - 如果获取失败，设置角速度为0

3. **格式化输出**：
   - 使用`string.format()`创建包含所有数据的字符串
   - 通过`gcs:send_text(0, ...)`发送到地面站

4. **循环调度**：
   - 每1000毫秒（1Hz）执行一次循环

## 应用场景

1. **飞行调试**：实时监控飞行器姿态响应
2. **性能分析**：分析飞行器在不同飞行模式下的角速度变化
3. **参数调优**：帮助调整PID参数，观察姿态控制效果
4. **故障诊断**：检测姿态传感器或控制系统的异常
5. **飞行训练**：帮助新手了解飞行器的姿态变化

## 技术特点

1. **数据完整**：同时输出姿态角和角速度
2. **单位转换**：自动将弧度转换为更直观的度数
3. **容错处理**：角速度获取失败时提供默认值
4. **低频率运行**：1Hz频率避免占用过多系统资源
5. **格式清晰**：输出信息结构清晰，便于阅读

## 输出信息解读

- **Ang R:15.2**：横滚角15.2°
- **P:-3.5**：俯仰角-3.5°（负值表示机头向下）
- **Y:45.0**：偏航角45.0°
- **Rate R:12.3**：横滚角速度12.3°/s
- **P:0.5**：俯仰角速度0.5°/s
- **Y:-2.1**：偏航角速度-2.1°/s

这个脚本是一个简单但强大的调试工具，为飞行器姿态控制的分析和优化提供了实时数据支持。通过监测这些关键参数，用户可以更好地理解和调整飞行器的动态行为。
