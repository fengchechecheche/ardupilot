# OpenDog四足机器人演示脚本分析

这是一个用于OpenDog四足机器人的演示脚本，实现机器人爪子的周期性挥动动作。

## 主要功能

### 1. **四足机器人关节控制**
- 控制12个伺服通道（对应OpenDog的12个关节）
- 使用PWM信号控制伺服电机位置
- 实现一个关节的正弦波运动，模拟挥爪动作

### 2. **动态PWM控制**
- 初始化12个通道的PWM值，大部分为1500（中位）
- 第3通道设置为2000（最大位置）
- 第6通道初始为1000（最小位置），并在正弦波作用下动态变化
- 第6通道在1000-2000之间周期性变化

### 3. **正弦波运动生成**
- 基于时间生成正弦角度值
- 将角度映射到PWM范围（1000-2000）
- 实现平滑的周期性运动

## 工作流程

### 初始化阶段
1. **创建PWM数组**：
   ```lua
   pwm = { 1500, 1500, 2000,
           1500, 1500, 1000,
           1500, 1500, 1500,
           1500, 1500, 1500 }
   ```

2. **发送启动消息**：
   ```lua
   gcs:send_text(0, "opendog demo starting")
   ```

### 主循环（5Hz运行）
1. **计算时间**：获取自系统启动以来的秒数
   ```lua
   local t = 0.001 * millis():tofloat()
   ```

2. **生成正弦角度**：
   ```lua
   local angle = math.sin(t) * 0.5
   ```
   - `t`：时间（秒）
   - `math.sin(t)`：正弦函数，周期为2π秒（约6.28秒）
   - `* 0.5`：限制角度范围为-0.5到0.5弧度

3. **计算第6通道PWM**：
   ```lua
   pwm[6] = math.floor(1500.0 + angle*500.0)
   ```
   - 基准值：1500（中位）
   - 变化范围：±500，对应PWM范围1000-2000

4. **设置所有通道输出**：
   ```lua
   for i = 1, 12 do
       SRV_Channels:set_output_pwm_chan_timeout(i-1, pwm[i], 1000)
   end
   ```
   - 循环设置12个通道
   - 通道索引从0开始（`i-1`）
   - 超时时间1000毫秒（1秒）

5. **循环调度**：每200毫秒（5Hz）运行一次

## 技术实现

### 1. **PWM信号控制**
```lua
SRV_Channels:set_output_pwm_chan_timeout(channel, pwm_value, timeout_ms)
```
- 参数1：通道号（0-11）
- 参数2：PWM值（通常1000-2000）
- 参数3：超时时间（毫秒），超时后恢复默认控制

### 2. **正弦运动计算**
```lua
-- 时间计算
local t = 0.001 * millis():tofloat()  -- 将毫秒转换为秒

-- 角度计算
local angle = math.sin(t) * 0.5  -- 生成-0.5到0.5弧度的正弦波

-- PWM映射
pwm[6] = math.floor(1500.0 + angle*500.0)  -- 映射到1000-2000范围
```

### 3. **PWM值说明**
- **1000**：最小位置（通常对应0°或-90°，取决于伺服配置）
- **1500**：中位位置（通常对应90°或0°）
- **2000**：最大位置（通常对应180°或+90°）

## 运动特性

### 1. **挥爪关节**（第6关节）
- **初始位置**：1000（完全收缩）
- **运动范围**：1000-2000（完全收缩到完全伸展）
- **运动周期**：约6.28秒（2π秒）
- **运动方式**：正弦波，平滑往复运动

### 2. **固定关节**（第3关节）
- **固定位置**：2000（完全伸展）
- **始终保持**：最大伸展位置

### 3. **其他关节**
- **全部保持**：1500（中位位置）
- **不参与运动**：保持静止状态

## 安全特性

### 1. **超时保护**
```lua
SRV_Channels:set_output_pwm_chan_timeout(i-1, pwm[i], 1000)
```
- 设置1000毫秒超时
- 如果脚本停止或出错，1秒后恢复默认控制
- 防止机器人失控

### 2. **PWM范围限制**
- 通过角度乘数（0.5）和PWM偏移（500）限制输出范围
- 确保PWM值在1000-2000的安全范围内

### 3. **整数输出**
```lua
math.floor(1500.0 + angle*500.0)
```
- 将浮点数转换为整数PWM值
- 避免小数PWM值可能引起的问题
