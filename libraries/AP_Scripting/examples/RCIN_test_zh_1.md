这是一个**遥控输入(RC Input)测试和演示脚本**，用于读取和演示ArduPilot系统中的遥控器输入功能。以下是详细功能分析：

## 核心功能
这是一个**遥控信号读取与控制功能演示脚本**，展示了如何从遥控器读取不同类型输入以及如何控制辅助设备。

## 主要功能模块

### 1. **遥控通道初始化**
```lua
local scripting_rc_1 = rc:find_channel_for_option(300)  -- 脚本输入通道1
local scripting_rc_2 = rc:find_channel_for_option(301)  -- 脚本输入通道2
local flip_flop = 0  -- 翻转标志变量
```
- 查找配置为脚本控制的遥控通道
- 使用RC选项参数：
  - **选项300**：用于读取归一化模拟输入
  - **选项301**：用于读取开关位置
  - 需要在ArduPilot参数中配置

### 2. **原始PWM信号读取**
```lua
pwm1 = rc:get_pwm(1)  -- 通道1的PWM值
pwm2 = rc:get_pwm(2)  -- 通道2的PWM值
pwm3 = rc:get_pwm(3)  -- 通道3的PWM值
pwm4 = rc:get_pwm(4)  -- 通道4的PWM值
```
- 读取前4个遥控通道的原始PWM脉宽值
- 典型PWM范围：1000-2000微秒
- 发送到地面站显示：`"RCIN 1:1500 2:1500 3:1500 4:1500"`

### 3. **归一化输入读取**
```lua
if scripting_rc_1 then
    gcs:send_text(0, "Scripting in 1:" .. tostring(scripting_rc_1:norm_input()))
end
```
- 读取配置为选项300的通道归一化值
- 归一化范围：通常为-1.0到+1.0
- 对应遥控杆的完整行程范围

### 4. **开关位置读取**
```lua
if scripting_rc_2 then
    local sw_pos = scripting_rc_2:get_aux_switch_pos()
    if sw_pos == 0 then 
        gcs:send_text(0, "Scripting switch is low")
    elseif sw_pos == 1 then
        gcs:send_text(0, "Scripting switch is middle")
    else
        gcs:send_text(0, "Scripting switch is high")
    end
end
```
- 读取配置为选项301的通道开关位置
- 返回值：0=低，1=中，2=高（对应三段开关）
- 发送相应的开关位置消息

### 5. **辅助功能控制**
```lua
rc:run_aux_function(28, flip_flop)
if (flip_flop == 0) then
    flip_flop = 2 -- switch high
else
    flip_flop = 0 -- switch low
end
```
- 执行辅助功能28（继电器1控制）
- `flip_flop`变量在0和2之间交替切换，模拟开关高/低状态
- 每次循环翻转继电器状态

## 工作流程

### 执行频率
- **1Hz频率**：每1秒执行一次循环
- 启动后立即执行一次

### 状态翻转逻辑
```
初始: flip_flop = 0
第一次循环: rc:run_aux_function(28, 0) → flip_flop = 2
第二次循环: rc:run_aux_function(28, 2) → flip_flop = 0
第三次循环: rc:run_aux_function(28, 0) → flip_flop = 2
...
```
- 继电器状态每秒翻转一次
- 0=关闭继电器，2=打开继电器

## 遥控配置要求

### 必要的参数设置
在ArduPilot中需要配置以下参数：
```
RCx_OPTION = 300  # 将某个通道分配给脚本输入1
RCy_OPTION = 301  # 将另一个通道分配给脚本输入2
```

### 典型配置示例
```
RC5_OPTION = 300  # 通道5作为模拟输入
RC6_OPTION = 301  # 通道6作为开关输入
```

## 技术细节

### 辅助函数28（继电器1）
- 在ArduPilot中，辅助函数28通常对应继电器1
- 参数：0=关闭，1=中间，2=打开
- 可用于控制灯、投放装置、相机快门等

### 遥控选项参数
- **300 (Scripting1)**：预留脚本输入通道1
- **301 (Scripting2)**：预留脚本输入通道2
- 这些是专门为脚本预留的选项
