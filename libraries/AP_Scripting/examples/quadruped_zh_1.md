这是一个**四足机器人（Quadruped）的运动控制脚本**，用于将ArduPilot Rover固件的控制输出转换为12个舵机信号，控制四条机器狗腿的运动。

## 核心功能
这是一个**四足机器人正向和逆向运动学控制器**，将传统车辆控制输入（横滚、俯仰、偏航、油门）转换为12个舵机角度，实现机器狗的行走和姿态控制。

## 系统架构

### 1. **硬件配置**
- **12个舵机控制**：每条腿3个关节（髋关节、大腿关节、小腿关节）
- **四条腿布局**：
  - 前右腿（FR）：输出1-3
  - 前左腿（FL）：输出4-6
  - 后左腿（BL）：输出7-9
  - 后右腿（BR）：输出10-12

### 2. **机器人几何参数**
```lua
FRAME_LEN = 80     -- 机身长度（前后距离）80mm
FRAME_WIDTH = 150  -- 机身宽度（左右距离）150mm
COXA_LEN = 30      -- 髋关节长度 30mm
FEMUR_LEN = 85     -- 大腿长度 85mm
TIBIA_LEN = 125    -- 小腿长度 125mm
```

## 主要算法模块

### 1. **步态生成系统**
#### 支持的步态类型：
- **交替步态（Alternating Gait）**：6步周期，对角线腿同时移动
- **波浪步态（Wave Gait）**：28步周期，每条腿依次移动

#### 步态参数控制：
```lua
x_travel     -- X轴行进距离（前后）
y_travel     -- Y轴行进距离（左右）
yaw_travel   -- 偏航旋转量
leg_lift_height = 50 -- 抬腿高度 50mm
```

### 2. **运动学计算**

#### A. **身体正向运动学** (`body_forward_kinematics`)
- 考虑身体旋转（横滚、俯仰、偏航）
- 考虑身体位置偏移（X、Y、Z）
- 计算每条腿在身体坐标系中的目标位置

#### B. **腿部逆向运动学** (`leg_inverse_kinematics`)
- 输入：腿末端在腿坐标系中的位置（x, y, z）
- 输出：三个关节的角度（髋关节、大腿关节、小腿关节）
- 使用几何三角函数计算关节角度

### 3. **控制输入映射**
```lua
throttle  → y_travel（Y轴移动）
yaw       → yaw_travel（偏航旋转）
roll      → body_rot_x（身体横滚）
pitch     → body_rot_y（身体俯仰）
height    → body_pos_z（身体高度）
```

## 工作流程

### 1. **初始化阶段**
- 设置舵机输出映射
- 计算腿部初始位置
- 选择步态类型
- 禁用方向舵解锁（防止误操作）

### 2. **主循环（update函数）**
1. **读取控制输入**：从车辆控制器获取横滚、俯仰、偏航、油门、高度
2. **步态计算**：根据输入计算下一步的步态序列
3. **运动学求解**：
   - 身体正向运动学 → 每条腿的目标位置
   - 腿部逆向运动学 → 每个关节的角度
4. **舵机控制**：将角度转换为PWM信号输出到12个舵机
5. **时序控制**：等待舵机移动到目标位置后继续下一步

### 3. **步态执行逻辑**
- **移动阶段**：腿在地面推动身体移动
- **抬腿阶段**：腿抬起并向前/后摆动
- **落地阶段**：腿放下接触地面
- **稳定阶段**：身体保持平衡

## 特殊处理

### 1. **舵机运动估计** (`servo_estimate`)
- 计算舵机从当前角度到目标角度所需时间
- 假设舵机速度：60°/0.24秒
- 等待最慢的舵机完成运动后再执行下一步

### 2. **休息姿态**
- 未解锁时：所有腿放下支撑身体
- 角度：髋关节±45°，大腿-90°，小腿40°

### 3. **方向控制**
```lua
servo_direction -- 调整每条腿的舵机旋转方向
gait_direction  -- 控制前进/后退方向
```

## 数学计算详解

### 1. **逆向运动学公式**
```
已知：末端位置(x, y, z)
计算：
1. 髋关节角度 = atan(x, y)
2. 水平距离 = √(x²+y²) - COXA_LEN
3. 斜边距离 = √(水平距离² + z²)
4. 大腿角度 = acos((FEMUR² - TIBIA² + 斜边²) / (2×FEMUR×斜边))
5. 小腿角度 = acos((FEMUR² - 斜边² + TIBIA²) / (2×TIBIA×FEMUR)) - 90°
```

### 2. **身体旋转补偿**
- 横滚旋转：影响腿的Z轴位置
- 俯仰旋转：影响腿的Z轴位置
- 偏航旋转：影响腿的X、Y轴位置

## 安全特性

1. **死区处理** (`travel_dz = 5`)：忽略微小的控制输入
2. **最大限制**：限制身体旋转和位置偏移在安全范围内
3. **解锁保护**：只有解锁时才执行运动控制
4. **舵机超时**：设置PWM输出超时保护

## 应用场景

### 1. **遥控操作**
- 使用遥控器控制机器狗行走、转向、调整姿态

### 2. **自主导航**
- 与ArduPilot导航系统集成，实现路径跟踪

### 3. **地形适应**
- 通过调整身体姿态适应不平坦地面

### 4. **稳定控制**
- 保持身体平衡，抵抗外部扰动
