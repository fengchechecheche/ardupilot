# 复活节彩蛋脚本分析

这是一个基于位置寻宝的"彩蛋"游戏脚本，主要用于演示ArduPilot Lua脚本的各种功能。

## 主要功能

### 1. **随机寻宝游戏**
- 在指定区域内随机生成目标点（经度偏移0-10米，纬度偏移0-100米）
- 当飞行器到达目标点（距离小于20米）时，得分增加并生成新目标
- 通过地面站消息显示得分和距离信息

### 2. **音频导航系统**
- **靠近提示音**：当飞行器靠近目标时播放`TUNE_TOWARDS`音调
- **远离提示音**：当飞行器远离目标时播放`TUNE_AWAY`音调
- **到达庆祝音**：当到达目标点时播放`TUNE_POINT`庆祝音调

### 3. **位置追踪与反馈**
- 实时计算飞行器当前位置与目标的距离
- 每5秒通过地面站发送距离信息
- 持续判断飞行器是靠近还是远离目标

## 技术演示

### 1. **Location对象操作**
```lua
-- 创建和初始化Location对象
local target = Location()
local top_left = Location()
top_left:lat(-353622666)  -- 纬度（度*1e7）
top_left:lng(1491650479)  -- 经度（度*1e7）

-- 位置偏移（东移，北移）
target:offset(math.random()*-100, math.random()*10)

-- 计算两点间距离
local dist = target:get_distance(current)
```

### 2. **音频控制**
```lua
-- 播放音调
notify:play_tune(TUNE_TOWARDS)
```

### 3. **地面站通信**
```lua
-- 发送文本消息到地面站
gcs:send_text(6, string.format("New target %d %d", target:lat(), target:lng()))
```

### 4. **定时与循环控制**
```lua
-- 获取当前时间（毫秒）
local now = millis()

-- 控制消息发送频率
if (now - last_notify_time_ms) > notify_interval_ms then
    last_notify_time_ms = now
    -- 发送消息
end
```

## 工作流程

### 初始化阶段
1. 定义接受距离、音调字符串
2. 创建目标位置和参考位置对象
3. 初始化距离记录、时间间隔和得分

### 游戏主循环（10Hz运行）
1. **获取当前位置**：通过`ahrs:get_location()`
2. **判断是否到达目标**：
   - 距离小于20米：播放庆祝音、得分加1、生成新目标
3. **定期通知**（每5秒）：
   - 发送当前距离信息
   - 判断移动方向：播放靠近或远离音调
4. **更新距离记录**：如果距离变化超过1米

## 关键参数

- **ACCEPTANCE_DISTANCE**：20.0米，到达目标的判断距离
- **notify_interval_ms**：5000毫秒，消息发送间隔
- **目标区域**：以(-35.3622666°, 149.1650479°)为参考点的100×10米矩形区域
- **距离变化阈值**：1.0米，用于判断靠近或远离

## 应用场景

1. **脚本教学**：演示ArduPilot Lua脚本的核心API使用
2. **功能测试**：测试位置获取、音频播放和地面站通信功能
3. **飞行训练**：作为有趣的导航练习游戏
4. **系统演示**：展示ArduPilot的高级脚本能力

## 技术特点

### 1. **位置坐标格式**
- 使用度*1e7的整数格式存储经纬度（如-353622666表示-35.3622666°）

### 2. **音调字符串格式**
- **MBNT255**：音调格式，包含节奏和音符
- **A#8**：音符和时长

### 3. **随机点生成**
- 使用`math.random()`生成随机偏移量
- 经度方向：0-10米随机偏移（东向）
- 纬度方向：0-100米随机偏移（北向）

### 4. **实时方向判断**
- 通过比较当前距离与上次距离判断飞行方向
- 使用1米阈值避免微小变化导致的频繁切换

## 游戏体验

1. **开始游戏**：脚本启动后生成第一个随机目标
2. **导航阶段**：根据音频提示飞向目标
   - 听到`TUNE_TOWARDS`音调：继续当前方向
   - 听到`TUNE_AWAY`音调：调整飞行方向
3. **到达目标**：听到庆祝音，得分增加，生成新目标
4. **持续游戏**：不断寻找新目标，累积得分

这个脚本是一个精心设计的教学示例，不仅展示了ArduPilot Lua脚本的强大功能，还通过游戏化的方式使学习过程更加有趣。它涵盖了位置计算、音频控制、地面站通信等关键技能，是理解ArduPilot脚本系统的优秀教材。
