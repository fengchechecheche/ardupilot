这个 Lua 脚本是 **ArduPilot 航点任务监控脚本**，用于实时监控无人机执行航点任务的状态。让我详细分析其功能：

## 主要功能
该脚本监控无人机执行任务时的航点信息，包括航点索引、距离、方位和横向误差，并提供进度百分比计算。

## 关键组件分析

### 1. **全局变量**
```lua
local wp_index          -- 当前航点索引
local wp_distance       -- 到当前航点的距离（米）
local wp_bearing        -- 到当前航点的方位角（度）
local wp_error          -- 航点横向误差（米）
local wp_max_distance   -- 最大距离（用于计算百分比）
local last_log_ms       -- 上次日志时间（但未使用）
```

### 2. **核心函数**

#### **`on_wp_change(index, distance)`**
- 当航点改变时触发
- 重置最大距离为当前距离
- 向地面站发送新航点通知
```lua
gcs:send_text(0, string.format("NEW WP: idx=%d, dist=%.01fm", index, distance))
```

#### **`refresh_wp_info()`**
- 获取当前航点信息
- 使用 ArduPilot API：
  - `mission:get_current_nav_index()` - 获取当前导航航点索引
  - `vehicle:get_wp_distance_m()` - 获取到航点的距离
  - `vehicle:get_wp_bearing_deg()` - 获取到航点的方位角
  - `vehicle:get_wp_crosstrack_error_m()` - 获取横向误差

#### **`log_wp_info(index, distance, bearing, error)`**
- 计算航点完成百分比
- 格式化并发送航点状态到地面站
```lua
local perc = wp_distance_max > 0 and 100-(100*(distance/wp_distance_max)) or 0
```

### 3. **主循环 `update()`**
- 每 1 秒执行一次（1Hz）
- 刷新航点信息
- 记录航点状态

## 输出信息格式
脚本会输出两种类型的消息：

### 1. **航点变更消息**
```
NEW WP: idx=3, dist=150.0m
```
- 当切换到新航点时发送
- 包含航点索引和初始距离

### 2. **定期状态消息**
```
WP: 3, 75.0m (50.0%), b: 45°, xe:2.5m
```
- 每 1 秒发送一次
- 包含：
  - 航点索引
  - 当前距离
  - 完成百分比（基于最大距离）
  - 方位角（四舍五入到整数）
  - 横向误差

## 进度百分比计算
脚本使用一种巧妙的方法计算航点完成进度：
```lua
local perc = 100 - (100 * (当前距离 / 最大距离))
```
- **最大距离**：在每个航点开始时记录初始距离
- **当前距离**：实时距离（逐渐减小）
- **百分比**：从 0%（初始距离）到 100%（到达航点）

## 应用场景
1. **任务执行监控**：实时了解无人机执行航点任务的进度
2. **调试和验证**：验证航点导航算法的准确性
3. **任务规划评估**：评估航点间距和路径规划效果
4. **训练和演示**：直观展示无人机导航过程

## 技术特点
1. **非侵入式监控**：只读取状态，不修改任务执行
2. **实时反馈**：1Hz 的更新频率提供实时状态
3. **百分比进度**：直观的完成度指标
4. **横向误差监控**：了解导航精度
5. **事件驱动通知**：航点变更时特别通知
