# AHRS方差打印脚本分析

这个Lua脚本用于以1Hz频率显示AHRS（姿态和航向参考系统）的方差信息，主要用于监控EKF（扩展卡尔曼滤波器）的状态和一致性。

## 主要功能

### 1. **EKF方差监测**
实时获取EKF滤波器的五个关键方差指标：
- **速度方差（vel_variance）**：速度估计的一致性指标
- **位置方差（pos_variance）**：位置估计的一致性指标
- **高度方差（height_variance）**：高度估计的一致性指标
- **磁力计方差（mag_variance）**：磁力计测量的一致性指标（返回Vector3f向量）
- **空速方差（airspeed_variance）**：空速测量的一致性指标（脚本中未显示）

### 2. **方差解读**
- **值为0**：测量值与EKF解算结果完全一致（理想状态）
- **值为1**：滤波器能接受的最大不一致性（阈值）
- **值>1**：可能存在传感器问题或模型不匹配
- **nil返回值**：方差数据不可用

### 3. **数据输出**
- 成功时输出格式：`"Variances Pos:X.X Vel:X.X Hgt:X.X Mag:X.X"`
- 失败时输出：`"Failed to retrieve variances"`

## 工作流程

### 主循环（1Hz运行）
1. **获取方差数据**：
   - 通过`ahrs:get_variances()`获取所有方差值
   - 该函数返回五个值：速度、位置、高度、磁力计和空速的方差

2. **数据处理**：
   - 检查是否成功获取数据（vel_variance不为nil）
   - 磁力计方差是三维向量，使用`:length()`方法获取其标量长度
   - 注意：空速方差被获取但未显示在输出中

3. **格式化输出**：
   - 使用`string.format()`创建包含四个主要方差的字符串
   - 通过`gcs:send_text(0, ...)`发送到地面站

4. **错误处理**：
   - 如果获取失败（返回nil），发送失败消息
   - 继续以1Hz频率运行，不中断脚本

## 应用场景

1. **EKF健康监控**：实时评估滤波器性能和一致性
2. **传感器诊断**：检测特定传感器（如磁力计）的问题
3. **飞行质量评估**：评估飞行中EKF估计的可靠性
4. **调试辅助**：在开发或调参时监控滤波器状态
5. **故障预警**：方差值异常升高可能预示传感器故障

## 技术特点

1. **专业指标**：提供EKF内部的关键一致性指标
2. **归一化显示**：所有方差值都是归一化的，便于比较
3. **向量处理**：正确处理磁力计的三维方差向量
4. **容错设计**：处理方差数据不可用的情况
5. **低开销**：1Hz频率避免对系统性能造成影响

## 输出信息解读示例

`"Variances Pos:0.2 Vel:0.1 Hgt:0.3 Mag:0.4"`

- **Pos:0.2**：位置方差0.2（良好，远低于阈值1）
- **Vel:0.1**：速度方差0.1（很好）
- **Hgt:0.3**：高度方差0.3（可以接受）
- **Mag:0.4**：磁力计方差长度0.4（需注意，可能受磁场干扰）

## 重要说明

1. **EKF专用**：该脚本仅在使用EKF时有效（AHRS_EKF_TYPE=2或3）
2. **动态变化**：方差值会随飞行条件和传感器质量动态变化
3. **阈值意义**：接近或超过1的值表示EKF可能无法完全信任相应传感器的测量
4. **综合判断**：应结合多个方差值和实际飞行状态综合判断

这个脚本是高级用户的强大诊断工具，通过监控EKF的方差指标，可以深入了解滤波器的工作状态和传感器数据的可靠性，有助于预防飞行问题和提高飞行安全性。
