# 数据记录脚本分析

这是一个用于记录飞行器姿态数据到SD卡文件和数据闪存的双重日志记录脚本。

## 主要功能

### 1. **双重日志记录系统**
- **SD卡CSV文件记录**：将数据保存为CSV格式的文本文件
- **数据闪存（Dataflash）记录**：将数据记录到飞行控制器的内部日志系统
- 同时记录时间戳、横滚角、俯仰角和偏航角

### 2. **CSV文件记录**
- 创建名为"AHRS_DATA.csv"的文件
- 使用追加模式（"a"），每次运行脚本都会在文件末尾添加数据
- 包含CSV表头：`Time Stamp(ms), roll(deg), pitch(deg), yaw(deg)`
- 每行数据包含时间戳和三个姿态角，以逗号分隔

### 3. **数据闪存记录**
- 使用两种不同的日志格式记录相同数据
- 支持多种数据类型格式（仅限于脚本支持的格式）

## 工作流程

### 初始化阶段
1. **定义文件信息**：
   - 文件名：`AHRS_DATA.csv`
   - 数据索引：roll(1), pitch(2), yaw(3)

2. **创建/打开文件**：
   - 使用`io.open(file_name, "a")`以追加模式打开文件
   - 如果打开失败，抛出错误
   - 写入CSV表头

### 主循环（1Hz运行）
1. **获取姿态数据**：
   - 通过`ahrs:get_roll()`等函数获取姿态角（弧度）
   - 使用`math.deg()`转换为角度
   - 存储在`interesting_data`表中

2. **写入SD卡文件**：
   - 调用`write_to_file()`函数
   - 格式：时间戳 + 三个姿态角
   - 使用`file:flush()`确保数据写入磁盘

3. **写入数据闪存**：
   - 调用`write_to_dataflash()`函数
   - 使用两种不同格式记录相同数据

4. **循环调度**：每1000毫秒（1秒）运行一次

## 技术实现

### 1. **SD卡文件操作**
```lua
-- 打开文件（追加模式）
file = io.open(file_name, "a")

-- 写入数据
file:write(tostring(millis()) .. ", " .. table.concat(interesting_data,", ") .. "\n")

-- 强制写入磁盘
file:flush()
```

### 2. **数据闪存日志记录**
```lua
-- 基本格式记录
logger.write('SCR1','roll(deg),pitch(deg),yaw(deg)','fff',
             interesting_data[roll],interesting_data[pitch],interesting_data[yaw])

-- 带单位和乘数的格式记录
logger.write('SCR2','roll,pitch,yaw','fff','ddd','---',
             interesting_data[roll],interesting_data[pitch],interesting_data[yaw])
```

### 3. **数据格式说明**
- **SCR1/SCR2**：日志名称（必须少于4个字符）
- **'fff'**：三个浮点数格式
- **'ddd'**：单位（度）
- **'---'**：乘数（无）

### 4. **脚本支持的数据类型**
根据注释，脚本仅支持以下格式字符：
- i, L, e, f, n, M, B, I, E, N

## 重要注意事项

### 1. **文件管理**
- **追加模式**：当前脚本使用追加模式，会导致文件无限增大
- **文件系统限制**：SD卡有容量限制，长时间运行可能填满存储
- **文件句柄**：脚本未包含文件关闭操作，在脚本停止时可能需要手动处理

### 2. **数据闪存限制**
- **日志名称限制**：必须少于4个字符且不与其他日志类型冲突
- **数据类型限制**：仅支持特定格式字符
- **存储空间**：数据闪存有容量限制，高频记录可能快速填满

### 3. **性能考虑**
- **I/O操作**：频繁的文件写入可能影响飞行控制器性能
- **时间戳精度**：`millis()`提供毫秒级时间戳
- **数据同步**：SD卡和数据闪存记录是同步进行的，可能产生延迟

## 脚本特性

### 1. **双重记录优势**
- **冗余备份**：数据在两个独立存储介质上备份
- **格式多样性**：CSV文件便于人工阅读，数据闪存便于专业工具分析
- **兼容性**：CSV文件可在任何文本编辑器或电子表格软件中打开

### 2. **数据完整性**
- **强制刷新**：使用`file:flush()`确保数据立即写入磁盘
- **错误处理**：文件打开失败时抛出错误
- **结构化存储**：明确的字段定义和数据格式

### 3. **扩展性**
- **易于修改**：可轻松添加新的数据字段
- **格式灵活**：CSV格式便于后续数据处理
- **配置简单**：通过修改参数调整记录频率和内容
