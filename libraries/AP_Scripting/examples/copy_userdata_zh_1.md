# 用户数据复制示例脚本分析

这个Lua脚本演示了如何在userdata对象上使用`copy()`方法进行复制操作，而不是简单的引用赋值。

## 主要功能

### 1. **Location对象的复制与操作**
- 创建一个Location对象`loc1`，设置经纬度为(-35, -122)
- 使用`copy()`方法创建`loc1`的副本`loc2`
- 对`loc2`进行偏移操作（东移3000米，北移5000米）
- 计算两个位置之间的东北方向距离差

### 2. **Vector2f对象的复制与操作**
- 创建一个Vector2f对象`v1`，设置x和y值为(-35, -122)
- 使用`copy()`方法创建`v1`的副本`v2`
- 修改`v2`的x和y值（分别增加100和300）
- 计算两个向量的差值

### 3. **输出结果**
- 通过地面站发送两条消息：
  1. Location对象的距离差：`"locdiff=(5000.00,3000.00)"`
  2. Vector2f对象的差值：`"vdiff=(100.00,300.00)"`

## 关键技术点

### 1. **深拷贝与浅拷贝的区别**
```lua
-- 错误做法：引用赋值，两个变量指向同一对象
local loc2 = loc1  -- 修改loc2会影响loc1

-- 正确做法：使用copy()方法创建独立副本
local loc2 = loc1:copy()  -- loc2是loc1的独立副本
```

### 2. **Location对象操作**
- `loc:lat(latitude)` / `loc:lng(longitude)`：设置经纬度
- `loc:offset(east, north)`：进行位置偏移（东移、北移，单位：米）
- `loc1:get_distance_NE(loc2)`：计算两个位置之间的东北方向距离差，返回Vector2f对象

### 3. **Vector2f对象操作**
- `v:x(value)` / `v:y(value)`：设置x和y值
- `v:x()` / `v:y()`：获取x和y值
- 向量减法：`v2 - v1`返回新的Vector2f对象

## 工作流程

1. **创建和复制Location对象**：
   - 创建loc1并设置经纬度
   - 使用copy()创建独立副本loc2
   - 对loc2进行偏移操作
   - 计算两个位置的距离差并输出

2. **创建和复制Vector2f对象**：
   - 创建v1并设置坐标
   - 使用copy()创建独立副本v2
   - 修改v2的坐标
   - 计算两个向量的差值并输出

## 应用场景

1. **数据独立性**：需要修改对象副本而不影响原始数据时
2. **坐标计算**：进行位置偏移、距离计算等地理空间操作
3. **向量运算**：进行二维向量加减等数学运算
4. **算法开发**：在编写复杂算法时确保数据隔离

## 重要概念

### **引用与副本的区别**
- **引用赋值**：多个变量指向内存中的同一对象，修改一个会影响所有
- **副本创建**：创建对象的独立拷贝，修改副本不影响原始对象

### **userdata类型**
- 在Lua中，userdata表示C语言数据结构的封装
- 通常由宿主程序（如ArduPilot）提供，具有特定的方法和属性
- 不能直接用Lua的赋值操作符进行深拷贝

## 脚本输出解释

1. **Location距离差输出**：
   - `"locdiff=(5000.00,3000.00)"`
   - 表示loc2相对于loc1在北方向偏移5000米，东方向偏移3000米
   - 与代码中的`loc2:offset(3000,5000)`一致（注意参数顺序是东移、北移）

2. **Vector2f差值输出**：
   - `"vdiff=(100.00,300.00)"`
   - 表示v2相对于v1在x方向增加100，y方向增加300
   - 与代码中的`v2:x(v2:x()+100)`和`v2:y(v2:y()+300)`一致

这个脚本是一个重要的教学示例，展示了在处理复杂数据类型时如何正确地进行对象复制，避免因引用共享导致的数据污染问题。对于开发复杂的飞行控制脚本来说，这是必须掌握的基础知识。
