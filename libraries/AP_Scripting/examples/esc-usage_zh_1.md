# ESC使用时间监控脚本分析

这是一个用于监控ToshibaCAN电调（ESC）使用时间的脚本，主要用于维护和预防性检查。

## 主要功能

### 1. **ESC使用时间监控**
- 检查前四个ToshibaCAN电调（索引0-3）的累计使用时间
- 仅在飞行器未解锁时进行检查，避免飞行中干扰
- 判断电调使用时间是否超过设定的安全阈值

### 2. **使用时间阈值管理**
- 默认设置最大安全使用时间为100小时
- 自动将小时转换为秒进行比较：`usage_sec_max = usage_hours_max*60*60`

### 3. **状态通知系统**
- **超过阈值警告**：当电调使用时间超过安全限制时，发送详细警告信息
- **数据获取失败**：无法获取电调使用时间时发送通知
- **使用时间正常**：所有电调使用时间均在安全范围内时发送确认消息

## 工作流程

### 初始化阶段
1. 设置最大安全使用时间为100小时
2. 计算对应的秒数：100小时 = 360,000秒

### 主循环（每5秒运行一次）
1. **检查飞行器状态**：仅在未解锁时运行检查
2. **遍历前四个电调**（索引0-3）：
   - 通过`esc_telem:get_usage_seconds(i)`获取每个电调的使用秒数
   - 标记是否成功获取到使用时间数据
   - 检查是否超过最大安全使用时间
3. **发送状态通知**：
   - 如果任何电调超过限制，发送详细使用时间信息
   - 如果无法获取使用时间数据，发送错误消息
   - 如果所有电调使用时间正常，发送确认消息

## 电调使用时间格式

当电调超过安全限制时，发送的消息格式示例：
```
ESC0: 120hrs 30min (limit is 100hrs)
```

- **ESC编号**：0-3
- **使用时间**：以小时和分钟显示
- **安全限制**：显示设定的最大安全使用时间

## 技术实现

### 1. **电调通信**
- 使用`esc_telem:get_usage_seconds(i)`获取指定电调的使用时间
- 仅支持ToshibaCAN电调，其他类型电调可能无法获取数据

### 2. **时间单位转换**
```lua
-- 将秒转换为小时和分钟
local usage_hours = usage_sec / 3600
local usage_minutes = (usage_sec / 60) % 60
```

### 3. **字符串格式化**
```lua
-- 构建警告消息
string.format("ESC" .. tostring(i) .. ": " .. tostring(usage_hours) .. "hrs " .. tostring(usage_minutes) .. "min (limit is " .. tostring(usage_hours_max) .. "hrs)")
```

### 4. **逻辑控制**
- 仅在未解锁时检查，避免飞行中产生干扰
- 使用标志变量跟踪状态：
  - `got_esc_usage`：是否成功获取任何电调的使用时间
  - `esc_over_max`：是否有电调超过安全限制

## 应用场景

1. **预防性维护**：定期检查电调使用时间，预防因老化导致的故障
2. **寿命管理**：跟踪电调累计使用时间，规划更换周期
3. **设备管理**：在多机队环境中，追踪每个电调的使用历史
4. **安全审计**：确保所有电调在使用寿命内，符合安全标准

## 安全特性

### 1. **非侵入式检查**
- 仅在飞行器未解锁时运行，避免干扰飞行控制
- 每5秒检查一次，低频率减少系统负载

### 2. **明确阈值**
- 提供清晰的安全使用时间限制（默认100小时）
- 可根据不同电调型号调整阈值

### 3. **详细报告**
- 超过限制时提供具体电调编号和使用时间
- 区分数据获取失败和使用时间正常的情况

## 配置选项

### 主要参数
```lua
-- 最大安全使用时间（小时）
local usage_hours_max = 100

-- 检查的电调数量
for i = 0, 3 do  -- 检查前4个电调
```

### 可调整参数
1. **检查的电调数量**：可修改循环范围以检查更多电调
2. **检查频率**：可调整`return update, 5000`中的值改变检查间隔
3. **安全阈值**：可根据电调型号和制造商的建议调整`usage_hours_max`

## 使用限制

1. **电调类型限制**：仅支持ToshibaCAN电调
2. **数据可用性**：电调必须支持使用时间报告功能
3. **连接要求**：电调必须正确连接到CAN总线并配置
4. **检查时机**：仅在未解锁时检查，飞行中不提供监控

这个脚本是一个重要的维护工具，通过定期监控电调使用时间，帮助用户预防因电调老化或过度使用导致的故障，提高飞行安全性和设备可靠性。对于专业无人机操作员和设备管理人员来说，这是一个有价值的诊断脚本。
