# Heli_IM_Col_Tune Lua 脚本

这是一个在设置传统直升机时非常有用的工具。它用于调整 `IM_STAB_COL_<X>` 输入曲线。通常情况下，调整 `IM_STAB_COL_2` 和 `IM_STAB_COL_3` 参数以使直升机在摇杆中位悬停，并获得维持悬停所需的精细度是比较麻烦的，除非有人在地面站（GCS）为你操作。此工具提供了一种更直观的方法，使用遥控发射器上的两个旋钮。

## 工作原理

一个旋钮控制与50%输入（即摇杆中位）相对应的输出值。另一个旋钮将控制总距在40%到60%输入值范围内的灵敏度（即40%到60%之间曲线的梯度）。然后，它将50%的值和梯度转换为 `IM_STAB_COL_2` 和 `IM_STAB_COL_3` 的适当值。当你对调整结果满意后，拨动发射器上的保存开关，脚本将保存参数值并退出。

脚本每0.5秒根据旋钮的位置更新一次参数，便于轻松调整直至获得理想的"手感"。

值得注意的是，此脚本保留了 ArduPilot 设置的约束条件：

0 <= `IM_STAB_COL_1` < `IM_STAB_COL_2` < `IM_STAB_COL_3` < `IM_STAB_COL_4` <= 100

因此，如果 `IM_STAB_COL_1` 或 `IM_STAB_COL_4` 的设置值会违反上述约束，在脚本更改 `IM_STAB_COL_2` 或 `IM_STAB_COL_3` 之后，本脚本将修改 COL_1 和 COL_4 的值以确保符合该规则。

## 限制

对旋钮控制的值施加的限制如下：

- 摇杆中位输出值可以在脚本初始化时的初始中位输出值基础上调整 +/- 30%。

- 最大梯度为 +100%。

- 最小梯度为 +5%。

## 设置与使用

- 如果尚未完成，请按照 ArduPilot 维基页面上的说明启用脚本功能。

- 为获得脚本的适当反馈，建议将 `SCR_DEBUG_LVL` 设为 3。

- 将 Heli_IM_Col_Tune.lua 加载到飞控的 'scripts' 文件夹中。

- 将对应于你希望用来控制摇杆中位输出值的旋钮的 RC 输入通道的 `RC<X>_OPTION` 参数设置为 300。

- 将对应于你希望用来设置总距在中位值附近灵敏度的旋钮的 RC 输入通道的 `RC<X>_OPTION` 参数设置为 301。

- 将对应于你希望用来保存参数并退出脚本的开关的 RC 输入通道的 `RC<X>_OPTION` 参数设置为 302。

- 请注意，脚本仅在首次启动飞控时注册已分配的 RC 功能。对 RC 分配的更改需要重启飞控。

- 请注意，`RC<X>_TRIM` 值将被忽略。

- 建议开始时将你的 `IM_STAB_COL_<X>` 曲线设置为默认值（分别为 0/40/60/100）。同样，建议开始时将控制50%输入的旋钮设置在中间位置，将控制梯度的旋钮设置到最大值。这样，你的参数值将从其默认值开始。

- 确保你的保存开关处于低位（未触发）。

- 重启你的飞控。

- 在稳定模式下飞行，并通过调整两个旋钮来获得你期望的总距"手感"。如果你计划使用比稳定模式更高级的自动模式，使直升机在摇杆中位悬停是明智的，这样可以确保更平滑地进入和退出"自动总距"模式（例如定高和绕点）。对调整结果满意后，将保存开关拨到高位。脚本将保存参数并退出。如果不保存参数，重启后它们将不会保留。

- 使用脚本调整完你的 `IM_STAB_COL_2` 和 `IM_STAB_COL_3` 值后，从飞控中移除脚本并重置 `RC<X>_OPTION` 参数。

- 如果你希望对 `IM_STAB_COL_1` 和 `IM_STAB_COL_4` 进行任何调整，现在可以使用常规参数进行调整。

## 输出消息

### "LUA: IM_COL 调参完成"

脚本已完成，除非重启否则不会再次运行。

### "LUA: RC 通道未设置"

一个或多个 RC 通道未设置为脚本通道（300、301 或 302）。请设置它们并重启飞控。

### "LUA: IM_COL 设置器已停止"

出现故障，脚本已退出。这是由于脚本无法读取 `IM_STAB_COL_<X>` 参数值引起的。在此之前会有另一条消息，说明哪个参数无法获取。

### "LUA: 参数已保存"

参数保存成功。

### "LUA: 参数设置失败"

设置参数失败。脚本将持续尝试设置参数而不会退出。如果此消息持续显示，请考虑降落并调查根本问题。
