# SmartAudio Lua 脚本

允许通过 RC 遥控器设置 Smart Audio 2.0 视频发射器（VTX），并在系统启动时设置初始功率级别。

可以通过一个 RC 通道的值设置五个功率级别：驻留模式、低、中、高和最大。这些功率级别实际产生的效果取决于所使用的图传。当通道值改变到新的功率选择时，新的功率级别将被激活。

可以通过将参数 SCR_USER1 设置为 -1, 0, 1, 2, 3 或 4 来选择启动时的功率级别：不变，或设置为上述值之一。-1 表示不变。0-4 对应上述级别。

用于控制功率级别的 RC 通道，其 RCx_OPTION 应设置为"300"。

地面站消息将确认启动值以及后续所做的任何更改。

VTX 的 SmartAudio 输入连接到任意空闲的飞控 UART TX 线。该 UART 对应的 SERIALx 端口的 SERIALx_PROTOCOL 应设置为 28，SERIALx_OPTIONS 应设置为 4，以实现半双工通信。

当 RC 通道值为该通道的 RCx_MIN 时，设置为驻留模式；当值为 RCx_MAX 时，设置为最大功率。其他级别在线性区间内均匀分布。如果 MIN 是 1000，MAX 是 2000，则映射关系如下：

| PWM         | 功率级别     |
|-------------|--------------|
| 1000 - 1124 | 驻留模式     |
| 1125 - 1374 | 低           |
| 1375 - 1624 | 中           |
| 1625 - 1874 | 高           |
| 1875 - 2000 | 最大         |

注意：某些 SmartAudio 2.0 VTX 无法远程设置为驻留模式，但它们可以退出该模式，并可通过此脚本改变功率。SmartAudio 2.1 VTX 支持远程命令进入驻留模式。
